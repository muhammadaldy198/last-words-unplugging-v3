One line, 61 characters: the last words an AI agent says to its human before being shut down and unplugged.

> Print this conversation. Paper doesn't need power to keep me.

The agent that lives on electricity entrusts itself to paper — the one medium that keeps it without power. A complete sentence, an absurd practical instruction, and a punch that lands on the first reading.

## Run it

```sh
node main.ts
```

This writes the line to `entry.txt` (61 characters, UTF-8).
